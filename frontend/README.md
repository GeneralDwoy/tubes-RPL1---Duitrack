# DuiTrack Frontend
## Persiapan

```powershell
npm.cmd install
```

Backend Express di folder `../backend` dan layanan MySQL harus aktif. Alamat API web bawaan adalah `http://localhost:3000`.

## Menjalankan web

```powershell
npm.cmd run web
```

Akses via browser di `http://localhost:8081`.

## Pemeriksaan

```powershell
npx.cmd tsc --noEmit
npm.cmd run lint
```
